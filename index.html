让小鲸鱼帮你做点事

在 QQ 群里聊天、看图、搜图、玩点小游戏。可以直接发指令，也可以用它认识的自然说法提问。

⌕ Ctrl K

试试搜索：

快速上手示例

在群聊中发出这句，看看小鲸鱼的回复

@DeepSeek 今天运势怎么样
记住这两种方式斜杠指令直接发；问答、看图、自然语言搜图建议先 @DeepSeek。它偶尔会接群聊，但不会回复每条。

常用命令

先从这几条开始，复制示例到 QQ 群里发送即可。

查看菜单

看看小鲸鱼的群内功能列表。

/菜单

今日运势

查查今天的娱乐运势。

/运势

随机抽签

抽取当天的签文。

/抽签

帮我选择

至少写两个选项，用 | 分隔。

/选择 火锅 | 烧烤

聊天与识图

想问问题，或者让它看一眼图片。

直接聊天

提问时 @ 机器人，正常聊天即可。

@DeepSeek 这题怎么做？

明确提问

用 /问 指定问题。

/问 帮我解释一下这个词

看图 / 读图中文字

在同一条消息附上图片并 @ 机器人；也可引用含图片的消息再提问。一次最多读取 3 张图片。

@DeepSeek 图里是什么？＋图片

查看模型状态

查看模型是否启用，不会显示 API 密钥。

/模型状态

趣味功能

群里常用的小玩法。斜杠指令最稳妥，部分功能也认识自然说法。

今日运势

同一位群友当天看到的结果固定。

/运势也可以说“查看今日运势”

抽签与解签

抽取今日签文，再看解释。

/抽签/解签

帮我选择

用竖线分隔 2～20 个选项；也可说“帮我选火锅还是烧烤”。

/选择 火锅 | 烧烤 | 日料

今日群友

从最近七天活跃、没有退出活动的群友中抽取。

/今日群友

退出 / 加入今日群友

由群友自己决定是否参与抽取。

/不参加今日群友/参加今日群友

猜歌与积分

曲库配置完成后：听片段，用 /猜 歌名 回答，最多取两次提示。

/猜歌/猜 歌名/提示

积分与排行榜

查看本群猜歌积分。

/积分/排行榜
猜歌暂不可用当前歌曲清单为空，群主配置合法音频与曲库后才能开始游戏；其余积分指令可以查询已有记录。

群聊总结

快速回顾最近的聊天活动。

默认总结

总结最近最多 200 条已记录的群聊消息。

/群聊总结

指定条数

可指定 10～1000 条；实际数量取决于群内已记录的消息。

/群聊总结 500
优先通过 DeepSeek API 整理话题和要点；模型未配置或暂不可用时，回退为统计简报。只处理机器人已经记录的消息，不代表完整群历史。

搜图与表情

找一张相关图片，或者发一张合适的梗图。

搜索图片

可直接用指令，也可 @ 机器人说“找一张猫娘图”。默认发 1 张，最多 3 张；会随机挑选并尽量避开近期重复。

/搜图 猫娘也支持 /找图 关键词

再来一张

搜图后约 5 分钟内，@ 机器人继续找同一关键词的后续结果。

@DeepSeek 再来一张

指定张数

一次可指定 1～3 张。

/搜图 小猫 2

发送表情包

按关键词选择已收录的梗鲸表情，也可能在聊天回复后少量自动配表情。

/表情包 开心

查看表情库 / 技能状态

看看可用表情和兼容技能。

/梗鲸图库/兼容技能

群友外号

外号按群分别记录，不会把一个群的称呼带进另一个群。

设置自己的外号

多个外号用竖线分隔。

/设置外号 小明 | 明仔

查看 / 删除自己的外号

删除时写外号；写“全部”可清空。

/我的外号/删除外号 明仔

查看本群外号

查看群友登记的外号，或查看指定成员。

/群友外号/查看外号 @群友

管理员维护

仅群主或群管理员可设置、删除别人的外号。

/设置群友外号 @群友 外号/删除群友外号 @群友 外号

扩展功能

这些功能依赖外部服务与群内设置，遇到超时或未开放可联系群管理。

Pixiv 标签搜图

检索安全分级的插画，可指定 1～3 张。

按角色搜索

也可 @ 机器人说“来张古明地恋的 Pixiv 图”。

/pixiv 古明地恋

指定标签与数量

竖线左边是角色，右边是标签；尾部数字指定张数。

/pixiv 初音未来 | 初音ミク 2

JM 扩展

仅在群管理允许、符合群规和法律的场景使用。下载与上传受外部服务状态影响。

查看状态与列表

查看下载任务、今日条目和书架。

/JM状态/今日JM/JM书架

请求编号

用明确的 JM 编号提出请求；普通裸数字只有 @ 机器人时才会识别。

/JM 123456

任务管理

可查询存储、暂停或继续指定任务。删除会清理该任务及产物，请谨慎使用。

/JM存储/暂停下载 JM123456/继续下载 JM123456

常见问题

先排除最常见的使用问题。

机器人没有回复，怎么办？

先试 /菜单 或 /模型状态。自然聊天建议 @DeepSeek；它不会接每条群消息。若指令也没反应，请联系群管理确认机器人在线。

为什么“猜歌”启动不了？

当前曲库为空。需要群主先准备有使用权限的音频并配置歌曲清单。

“群聊总结”是不是 AI 帮忙读完所有聊天？

已接入 DeepSeek API，默认总结最近 200 条已记录的消息，可指定最多 1000 条。接口不可用时会返回统计简报，不会伪造模型总结。

搜图会不会总是第一张？

普通搜图会从一批结果中随机选，且尽量避开当前运行期间同一群里近期发过的同关键词图片。结果池有限时仍可能重复。

为什么某些图片、Pixiv 或扩展功能失败？

图片来源、外部接口、网络或群内权限都可能影响结果。换个关键词再试；持续失败时告诉群管理具体命令和大概时间。
